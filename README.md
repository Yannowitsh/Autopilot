# Autopilot-DM

Extension Chrome et Firefox (aussi sur Android) : enchaîne l'Aventure ou la chasse, résout la vérification de présence, surveille l'énergie, échange des objets entre deux comptes via l'HDV et envoie des alertes sur Discord.

## Installation

1. **Code → Download ZIP** sur cette page, puis décompresse le ZIP où tu veux le garder (par exemple dans `Documents`).
2. Ouvre `chrome://extensions` et active le **Mode développeur** (en haut à droite).
3. **Charger l'extension non empaquetée**, puis choisis le dossier **`extension`**.
4. Pour l'échange entre deux comptes : dans **Détails** de l'extension, active **« Autoriser en navigation privée »**.

## Mises à jour

Quand une nouvelle version sort, la popup de l'extension l'indique et un message s'affiche en jeu :

1. Clique **« ⬇️ Installer »** dans la popup, ou sur le message en jeu.
2. Sur la page qui s'ouvre, clique **« Installer la mise à jour »**. L'extension télécharge la nouvelle version, remplace ses fichiers et se recharge toute seule. Les onglets du jeu se rechargent aussi.

**La première fois**, Chrome te demande de choisir le dossier `extension`, celui indiqué dans `chrome://extensions` → Détails → « Chargée depuis », puis d'autoriser sa modification. Coche **« Autoriser à chaque visite »** si Chrome le propose : ensuite, c'est un seul clic.

En secours, tu peux aussi double-cliquer **`mettre-a-jour.bat`** dans le dossier `extension`, puis recharger l'extension dans `chrome://extensions`.

Tes réglages (webhook Discord, file d'échange…) sont conservés : ils sont stockés dans Chrome, pas dans le dossier.

## Version Firefox / Android

La même extension tourne sur **Firefox** (ordinateur et Android, version 142 ou plus). Chrome sur Android et Brave n'acceptent pas les extensions.

1. Sur le téléphone, installe **Firefox** depuis le Play Store.
2. Télécharge le fichier **`.xpi`** de la [dernière version](https://github.com/OWNER/Autopilot-DM/releases/latest).
3. Firefox → **Paramètres** → **À propos de Firefox** → touche 5 fois le logo Firefox (menu de débogage), reviens dans **Paramètres** → **Installer le module depuis un fichier** → choisis le `.xpi`.
4. Sur le site du jeu, menu **⋮** → **Extensions** → **Autopilot-DM** ouvre la popup. Si elle affiche « ⚠️ L'extension n'a pas encore accès au site du jeu », touche **🔓 Autoriser l'accès**.

Les réglages de l'extension (notifications Discord, délais, rechargements, modules…) s'ouvrent aussi dans un onglet depuis le menu 🤖 en jeu, bouton **⚙️ Réglages de l'extension**, ou depuis **Modules complémentaires** → **Autopilot-DM** → **Paramètres** (Firefox) / clic droit sur l'icône → **Options** (Chrome).

Firefox installe ensuite les nouvelles versions tout seul (le bouton **⬇️ Installer** ouvre la page de la dernière version). Il vérifie environ une fois par jour ; pour forcer : `about:addons` → roue dentée → **Rechercher des mises à jour** (sur Android : Modules complémentaires → Autopilot-DM).

**Builds de test** (préversion « test-&lt;branche&gt; », numéro à 4 chiffres comme 2.15.1.27) : elles suivent leur propre canal et se mettent à jour toutes seules à chaque nouvelle build de leur branche. Une build de test garde ce canal : pour revenir aux versions de `main`, désinstalle-la puis installe le `.xpi` de la dernière release (sans ça, Firefox voit 2.15.1.27 plus récente que 2.15.1). Les builds de test d'avant la 2.15.1 suivent encore `main` : installe une fois la nouvelle à la main.

Sur téléphone, garde Firefox au premier plan et le téléphone branché : tant que le pilote tourne, l'extension garde l'écran allumé ; en veille ou en arrière-plan, Android gèle la page et le farm s'arrête. **À tester : 🔊 Garder actif en arrière-plan** (popup → Réglages, décoché par défaut). Tant que le pilote tourne, l'extension joue en boucle un son inaudible. Un onglet qui « joue du son » n'est pas ralenti par Firefox, et Android ne met pas Firefox en pause quand tu passes sur une autre appli ou éteins l'écran, comme pour une appli de musique : une notification « lecture en cours » reste affichée. Pour que ça tienne après les rechargements du pilote, autorise la lecture automatique pour le site du jeu : Firefox → **Paramètres** → **Autorisations des sites** → **Lecture automatique** → **Autoriser l'audio et la vidéo**. Pense aussi à mettre la batterie de Firefox en **Sans restriction** (Paramètres Android → Applications → Firefox → Batterie). Certains téléphones coupent quand même les applis en arrière-plan. L'échange entre deux comptes n'est pas disponible sur Firefox.

Sur téléphone, **📈 Rentabilité des zones** affiche une carte par groupe (zone et ▶ en haut, XP et kamas dessous) ; touche une carte pour voir ses détails (combats, moyenne brute, durée type).

Les fichiers `.xpi` sont fabriqués par GitHub Actions (`.github/workflows/firefox.yml`) : signés par Mozilla pour chaque nouvelle version de `main` (secrets du dépôt `AMO_JWT_ISSUER` et `AMO_JWT_SECRET`, clé d'API de [addons.mozilla.org](https://addons.mozilla.org/developers/addon/api/key/)), et une préversion de test « test-&lt;branche&gt; » pour chaque push sur une autre branche.

## Mode saison (saison Héroïque)

Pendant une saison Héroïque, une défaite contre un **boss** tue définitivement le perso de saison ; une défaite contre des monstres de chasse ne coûte rien. Le mode **🛡️ Mode saison** s'active **tout seul** dans chaque onglet où tu joues ton perso de saison (le jeu l'indique dans chaque page) : sa case est alors cochée et grisée. Un autre onglet ou une fenêtre privée sur ton perso principal n'est pas concerné et garde l'Aventure et l'Ascension. Tu peux aussi le cocher à la main (menu 🤖 → Activité, ou popup → Réglages) : il s'applique alors à tous les onglets. Avec le mode saison :

- le pilote ne fait **que de la chasse** (zone choisie) : Aventure (étapes de boss) et Ascension sont grisées, et le pilote s'arrête avec un message s'il n'est pas en chasse ; le bouton **▶** refuse les pages Aventure et Ascension ;
- le boss de chasse automatique n'est jamais tenté ;
- l'énergie n'est plus surveillée (combats gratuits en saison).

L'énergie n'est pas surveillée non plus quand le jeu l'affiche illimitée (« ∞ » dans l'en-tête : 7 premiers jours d'un compte, cadeau jusqu'au 15/10…).

Le farm de drop, le 📈 Leveling et l'échantillonnage passent par la chasse : ils restent disponibles et ne font que des chasses (le pilote attend qu'ils aient choisi leur zone). Une pause énergie en cours est levée dès que le mode saison s'active.

## Farm de drop

Dans l'optimiseur, avec **Chercher dans le bestiaire** (et **Drops de monstres uniquement**, coché par défaut : pas d'objets « bonus de victoire » ni de boss), le bouton **🐉 Aller dropper** (aussi dans la bulle ❤️ Favoris) liste tous les objets du build (à looter ou déjà possédés, pour monter leur tier) et tes objets favoris — les exemplaires que tu as déjà (inventaire + porté) sont affichés et déduits du tier voulu : coche ceux à farmer (rien n'est coché par défaut ; les « objets bonus de victoire » d'une zone sont farmables aussi, chance non publiée), ils passent dans la **liste de courses** où tu choisis le tier voulu pour chacun (T1 = 1 exemplaire, T2 = 3, T3 = 9, T4 = 27, T5 Rayonnant = 81) : la fenêtre affiche ta meilleure chance et le nombre de combats estimé. Le champ **+ N** à côté du tier ajoute N exemplaires à farmer en plus du tier voulu, même si le tier est déjà atteint (ex. Rayonnant +5 = 81 exemplaires, + 1 = 82 en tout) : le farm continue jusqu’à les avoir. **Fusion auto** (cochée par défaut, dans la liste de courses) : pendant le farm (toutes les 5 min, entre deux combats) et à la fin, 3 exemplaires d'un objet de la liste → tier suivant, jusqu'au tier voulu — seulement les objets de la liste, jamais les autres, et jamais les exemplaires sous cadenas (le cadenas se gère en jeu) ; bouton **⚡ Fusionner la liste** pour le faire tout de suite. La liste de courses est gardée et se trouve dans la bulle **❤️ Favoris** (avec tes builds et objets favoris ; 🛒 + sur un favori pour l'y ajouter), même après l'arrêt du farm. **Lancer le farm** passe le pilote en mode Chasse : il scanne toutes les zones utiles et attaque le groupe qui contient le plus de monstres lâchant un objet voulu (scan refait à chaque changement de zone), compte les objets reçus en fin de combat et change de zone quand celle-ci n'a plus rien à donner ou plus de groupe utile. 5 défaites d'affilée dans une zone : elle est abandonnée (notification) et on passe à la suivante. Arrêt + notification Discord quand tout est droppé, ou quand plus aucune zone n'a de groupe utile (avec la raison). Le suivi s'affiche dans le menu 🤖 (■ Arrêter le farm) ; le mode de combat est celui choisi (Auto du jeu / par poids).

## 📈 Leveling

Menu 🤖 → **📈 Leveling jusqu'au niveau 200** : le pilote chasse en boucle le groupe qui rapporte le plus d'XP par combat dans les zones autour de ton niveau (±20 niveaux, zones que tu peux attaquer). Il ne prend que des groupes assez sûrs : la prudence monte avec les victoires et baisse à chaque défaite. Il met tes points en Sagesse, équipe Sagesse > Puissance > Vitalité, et s'arrête au niveau 200 avec un chrono.

Le choix du groupe est revu :
- tous les 5 niveaux (tous les 2 niveaux avant le niveau 30) ;
- plus tôt si l'écart de niveau commence à réduire l'XP du groupe farmé ;
- au renouvellement des groupes, environ toutes les 3 minutes ;
- après une défaite.

Si le meilleur groupe est celui en cours, il est relancé directement, sans repasser par la page de zone. Au renouvellement des groupes, le pilote repasse toujours par la page de zone : l'ancien bouton de relance visait un groupe disparu. Si la relance échoue 3 fois, ou si l'écran de fin reste affiché plus d'une minute, le pilote recharge d'abord l'écran de fin (une page restée inerte après un rechargement ne réagit plus au clic : le groupe est ainsi gardé) ; après 2 rechargements sans succès, il rescanne et repart de la page de zone. Ça vaut aussi hors Leveling (chasse, Chemin, Ascension), qui repartent alors de la page du mode. Mesuré sur le compte de test (perso de saison, un niveau par combat) : le temps passé à scanner passe de 82 s à 34 s sur 7 minutes, et 13 combats gagnés au lieu de 9.

## 👑 Farm archi / avis de recherche

Menu 🤖 → section **🎯 Avis & 👑 archis** → **👑 Farmer les cibles** (à côté : nombre de **combats / groupe**, 5 par défaut). Le pilote farme en boucle :
1. il scanne les zones de la **tranche de niveaux** (champs « Niveaux » de la section ; vides : ton niveau ±20), en ignorant celles au-dessus de ton niveau ;
2. il attaque le **meilleur groupe** : le plus de cibles (types cochés : 🎯 avis, 👑 archimonstres ; au moins « N cible(s) dans le même combat »), à égalité celui avec le plus d'archimonstres, puis le plus faible niveau total ;
3. il le refait le nombre de combats choisi, puis rescanne et rejoint le meilleur groupe suivant (un groupe déjà farmé n'est pas repris avant son renouvellement).

Si le groupe est renouvelé avant la fin (toutes les ~3 min), le pilote rescanne aussitôt. Après 3 défaites d'affilée sur un groupe, il l'abandonne (notification) et passe au suivant. S'il ne trouve aucune cible, il attend le prochain renouvellement des groupes et rescanne. Le cadre violet du menu affiche le groupe en cours, le numéro du combat et les victoires ; **■ Arrêter** arrête le farm et le pilote. Pas disponible en mode saison.

## 🔮 Farm orbe (pious)

Menu 🤖 → section **🎯 Avis & 👑 archis** → **🔮 Farm orbe (pious)**. Le pilote farme les pious (niveaux 11–15) en boucle :
1. il scanne les zones où vivent les pious (lues dans le bestiaire : Village d'Amakna, Sufokia, Astrub, Bonta, Brâkmar, Milifutaie…) ;
2. il attaque un groupe fait **uniquement de pious classiques** — ni archimonstre, ni avis de recherche, ni autre monstre : **4 pious** de préférence, sinon **3** (à égalité, le plus faible niveau total) ;
3. il relance ce groupe en boucle jusqu'au renouvellement des groupes (~3 min) ou jusqu'à ce que la relance échoue, puis rescanne (et reprend un groupe de 4 s'il y en a un).

S'il n'y a aucun groupe de 3 pious ou plus, il attend le prochain renouvellement et rescanne. Une zone dont le groupe reste sans bouton « Attaquer » pendant 45 s est écartée ; après 3 défaites d'affilée, le groupe est abandonné (notification 🐉 Farm de drop). Le cadre bleu du menu affiche le groupe en cours et les victoires ; **■ Arrêter** arrête le farm et le pilote.

## 🎁 Tout réclamer

La bulle **🎁** (en bas à gauche, à côté de ❤️) réclame en un clic tout ce qui attend :
- les **succès** (coffres et, depuis le 10/10, énergie) ;
- la **série de connexion** du jour ;
- les **quêtes du jour** terminées ;
- le **coffre de l'Élan** (tous les 25 combats, 3 par jour) et ses **défis du jour** réussis ;
- les **croquettes** du compagnon (toutes données) ;
- la **grotte de l'Aéfka** : son butin si elle tourne depuis au moins 1 h, puis elle est relancée.

Un message résume ce qui a été réclamé. Les défis de l'Élan ne sont réclamés que s'ils sont vraiment réussis, comme le montre la page du jeu (le serveur ne le vérifie pas lui-même).

## Bouton ▶ / ⏸

Au-dessus de la bulle 🤖 : **▶** (vert) démarre le pilote sur cet onglet et relance en boucle le combat de la page — zone de chasse, aventure, ascension, Dimension Écarlate, Faille du Kralamoure, arène, Abysses ; sur un combat, son type est lu dans la page (le combat en cours est pris en main). Un combat qui ne se relance pas (boss de chasse…) ne démarre rien. Sur une autre page, c'est l'activité choisie dans le menu. **⏸** (rouge) arrête le pilote.

L'onglet du pilote peut rester en arrière-plan : les pages du jeu s'y affichent quand même (avant, une page chargée onglet caché restait sur « Chargement… » et le pilote attendait ton retour). Chaque combat lancé par le pilote compte comme de l'activité pour le jeu. Si le jeu te croit quand même inactif (« Tu étais inactif », après 10 min sans combat), le pilote clique sur **Je suis là, je reviens** et reprend. Si le serveur est plein, il attend dans la file d'attente au lieu de recharger la page en boucle.

**Rythme humain** : dans tous les modes (chasse, farms, Chemin, Ascension, Dimension, Kralamoure, arène, Abysses, boss de chasse), le pilote ne lance jamais deux combats à moins de 3,5 à 4,5 s d'écart sur un même onglet, même si le « Délai entre combats » de la popup est réglé plus bas. Le dev a fixé la limite humaine à ~3 s par combat, relance comprise : en dessous, c'est considéré comme une macro.

## Activités

Menu 🤖 → **🗺️ Activité** (ou popup → Réglages → Mode) :
- **Continuer** (par défaut) : quand le pilote démarre (popup, menu 🤖), il reprend l'activité de la page affichée, comme ▶ : la zone de chasse ouverte, le Chemin, l'Ascension, la Dimension, la Faille, les Abysses, ou le combat en cours. Sur une page sans activité (accueil, inventaire…), il garde la dernière ;
- **Aventure**, **Chasse**, **Ascension** : comme avant ;
- **Dimension** (Dimension Écarlate de ta guilde) : le pilote reprend la descente en cours (« Reprendre : vague N »), sinon il en ouvre une à la difficulté choisie (Rosée → Sanguinaire, 20 énergie). Chaque vague, **boss et Seigneur compris**, est lancée « à la main » puis jouée par ton moteur de combat (Auto par poids avec tes poids et stratégies, ou Auto du jeu) : l'Auto du jeu s'arrêtait avant chaque boss. Quand la descente se termine (défaite), une nouvelle est ouverte, sauf si « nouvelle descente à la fin » est décoché ;
- **Kralamoure** (Faille de ta guilde) : un combat dès que le Kralamoure est prêt (toutes les 20 minutes, 100 essais par jour), joué en 10 tours avec le mode Kralamoure de l'Auto par poids. Entre deux combats, le pilote affiche l'heure du prochain.
- **Arène** : le pilote défie **une fois** chaque adversaire de la liste pas encore affronté dans les 24 h (ceux marqués « Déjà affronté » sont passés : le gain d'Elo y est réduit), puis s'arrête. Avant **chaque** défi, il relit les tickets (« X du jour + Y en stock ») : 1 ticket par défi, d'abord les 10 gratuits du jour ; le stock (tickets des coffres) n'est utilisé que si la case **utiliser aussi les tickets en stock** est cochée (menu 🤖, sous les activités). Sans ticket utilisable, le pilote s'arrête et indique combien d'adversaires restent. Un défi refusé par le jeu arrête aussi le pilote, avec le message du jeu.
- **Abysses** (mode rogue-like, 1 000 étages, tout le monde repart de 6 PA, 3 PM, 100 partout) : le pilote fait **chaque choix** puis joue **chaque étage par poids**, boss Enragés compris (tous les 5 étages, combat manuel obligatoire : l'Auto du jeu ne les joue pas, et elle choisirait elle-même tes sorts et tes bonus). Il ne se sert ni de tes poids ni de ta tierlist (ton équipement ne compte pas ici) :
  - **choix du sort** (étage 1, puis après chaque boss Enragé) et **choix du bonus** (après les autres étages) : pour chaque proposition, il calcule ton meilleur tour possible (chaque sort jusqu'à 3 fois par tour, l'arme 1 fois, 2 sorts de soin ou de bouclier au plus) avec tes stats et contre le boss du dernier combat, et prend celle qui te fait descendre le plus loin : dégâts par tour (lignes multiples, zone, Puissance, stat de l'élément, critique, vision spectrale des PO) × temps de survie (résistances, esquive des PM : 1 % par PM jusqu'à 50 %, boucliers, soins, retraits de PA, invisibilité). Les **PA** passent en premier tant que tes sorts peuvent les dépenser ; Invisibilité, debuff de résistances (Ouginak), sorts de zone et à plusieurs lignes ressortent d'eux-mêmes. Comme chaque sort se lance 3 fois par tour, quelques bons sorts suffisent à remplir tes PA : un sort qui ne fait pas mieux par PA que ceux que tu as déjà est noté 0 (il ne changerait pas ton tour) ; si les trois sont à 0, c'est celui qui frappe le plus fort par PA qui est pris. Presque tous les étages n'opposent qu'un boss : la zone y compte peu. La Vitalité donne 1 PV par point ; elle remonte quand tes PV approchent du coup de grâce des boss (coup lourd après Rage : environ 2,2 fois leur attaque), sinon on finit tué d’un coup comme à l’étage 60. Les passifs de classe ne s’appliquent pas dans les Abysses (ni dans le calcul). Le détail des notes est dans le journal, et menu 🤖 → **🕳️ Compte rendu des Abysses** montre, descente par descente, chaque choix fait (✔) face aux autres propositions (effets des sorts, rareté des bonus, note de chacun, PA / PV et deck du moment) ; **📋 Copier** donne un texte à m'envoyer pour revoir les choix (5 dernières descentes gardées) ;
  - **en combat** : le plan de tour (comme en Ascension) avec les lancers multiples, la limite de 2 sorts de soin ou de bouclier (dégâts + soin compris, comme Eau-de-vie), la vraie valeur des buffs, des debuffs (dégâts gagnés sur leur durée) et de l'Invisibilité (attaque esquivée), joués avant les dégâts ; les règles annoncées de chaque boss sont prises en compte, toutes à la fois quand il y en a plusieurs (Miroir, Malédiction des soins, trop de cartes, même élément, Échange de vie, PA comptés, Deuxième souffle, Rage…) ;
  - **deck** (10 sorts au plus, les autres attendent dans « Mes autres sorts ») : **avant chaque étage**, s'il y a des sorts en attente, le pilote revoit le deck pour ton build du moment (stats, PA, dernier boss) et garde les 10 meilleurs ; les sorts inutiles restent de côté, le deck reste toujours plein ;
  - à la **fin de la descente** (défaite), le pilote **s'arrête** et prévient sur Discord (alertes défaite) : il ne relance jamais une descente tout seul. Démarré sur la page des Abysses sans descente en cours, il en lance une (en reprenant au point de contrôle si le jeu le propose).

Dimension, Kralamoure et Arène sont réservés au personnage principal (pas en mode saison).

**🐉 Boss de chasse auto** (popup → Réglages → « Tenter le boss de chasse auto », coché par défaut) : quand le boss de chasse apparaît (toutes les 20 minutes, présent 5 minutes, un seul essai), le pilote termine le combat en cours sans relancer, puis tente le boss **dans le même onglet** (page Chasse → « Affronter le boss », 2 énergie), le joue avec ton moteur de combat, et reprend ensuite son activité (zone de chasse, Chemin, Ascension, Dimension, Kralamoure, arène). En chasse, si le groupe suivi (avis de recherche, archimonstre) a été renouvelé pendant le boss, le pilote en choisit un autre au lieu de s'arrêter : un groupe de la zone qui contient encore une cible, sinon le plus dur ; en leveling, la zone est rescannée. Le boss n'est pas tenté s'il repart dans moins de 45 secondes, ni pendant une pause, ni en mode saison. Résultat envoyé sur Discord (alertes boss).

**🎡 Roue Bouftou auto** (popup → Réglages → « Roue Bouftou auto », coché par défaut) : tant que le pilote est activé (même en pause faute d'énergie), il tourne la Roue Bouftou dès qu'elle est disponible (un tour toutes les 3 heures par compte), sans quitter sa page ni interrompre le combat. Le lot gagné s'affiche dans le jeu et part sur Discord (notification « 🎡 Roue Bouftou », jackpot signalé). Jamais en mode saison : la roue y est fermée. Avec deux comptes, chacun garde son propre compte à rebours.

## Modules

Dans la popup de l'extension (icône en haut à droite de Chrome), bloc **Modules** : coche ou décoche chaque module (Auto par poids, Fusion, Auto-équipement, Tierlist, Optimiseur, Avis de recherche, Échange entre comptes). Un module décoché disparaît du menu 🤖 en jeu et ses boutons sont retirés des pages du jeu. Le pilote (aventure, chasse, ascension) est toujours là.

## Auto par poids

Menu 🤖 → Activité → **Combat** : **Auto du jeu** (le bouton Auto du site) ou **Auto par poids** : le pilote joue lui-même les cartes, sans animation, avec une courte pause aléatoire entre deux actions (réglable). La vérification de présence (« Es-tu toujours là ? ») qui tombe en plein combat est résolue sans quitter l'Auto par poids : avant, y répondre relançait l'Auto du jeu pour un tour. La pioche ne vise que les cartes réellement piochables (ni en main, ni jouées, ni en recharge) : avant, un deck de 7 cartes avec un sort en recharge faisait refuser la pioche à chaque tour, et au 6e refus le combat finissait en Auto du jeu. L'arme affichée dans 🎯 Poids des cartes (et utilisée par l'optimiseur) est celle du dernier combat joué, Auto par poids compris. **Roublard** (patch du 17/10 : les bombes n'explosent plus seules, Kaboom les fait toutes sauter avec +20 % de dégâts par bombe, 10 au plus) : le pilote pose ses bombes et ne lance Kaboom que lorsqu'il ne peut plus en poser (plus de PA ou de carte bombe ce coup-ci) ou qu'il en a 10, jamais sans bombe posée.

**Jouer comme un joueur** (case sous « Auto par poids ») : au lieu d'envoyer les actions directement au jeu (le plus rapide : rien ne s'affiche, la page se recharge à chaque fin de combat), le pilote clique la cible puis la carte dans la page, comme toi : tu vois les cartes taper, il attend la fin de chaque animation (tour ennemi compris) avant l'action suivante, puis l'écran de fin s'affiche sans rechargement et il clique la suite. Plus lent, mais vu du jeu c'est exactement comme si tu jouais. Vaut aussi pour le bouton « 🎯 Jouer ce combat par poids ».

**🎯 Poids des cartes** (menu 🤖, ou bouton en bas à droite de la page `/deck`) règle chaque carte, deck par deck ou dans toute la collection (avec recherche), et l'arme : à chaque action, le pilote garde la combinaison de cartes jouables qui tient dans tes PA avec le plus gros total de poids, et joue la plus lourde en premier, mais toujours les sorts à une ligne de dégâts avant ceux à plusieurs lignes et l'arme (un lancer à plusieurs lignes remet le bonus « une ligne » à zéro pour le reste du tour). Exception avec le **Dofus Pourpre** (1er sort de dégâts du combat doublé) : si doubler le plus gros sort à plusieurs lignes rapporte plus que doubler le meilleur sort à une ligne, bonus perdu par les sorts à une ligne du tour déduit, le pilote l'ouvre avec ce sort (après les buffs du tour) ; l'optimiseur compte le même choix. Poids **0** = jamais jouée ; **tous les N tours** = au plus une fois tous les N tours (pour les buffs qui durent). Les soins ne sont joués que sous un seuil de PV. Depuis la mise à jour du jeu du 14/10, **2 sorts de soin ou de bouclier au plus par tour** (3 pour l'Eniripsa et le Sacrieur ; partout, Ascension, Dimension écarlate et Colisée compris) : le pilote n'en tente pas un de trop, et le plan de tour de l'Ascension compte chaque soin ou bouclier à 40 % de tes PV max au plus (25 % avant le 16/10). **Maîtrise des Popokémons** (tes coups ne peuvent plus tuer pendant 5 tours) n'est jamais lancée par le pilote ni proposée dans un deck conseillé. **Coup final** : quand les cartes de dégâts en main (et l'arme) suffisent à tuer tous les ennemis ce tour, sans buff, le pilote ne joue qu'elles, sur les bonnes cibles (pas de buff, bouclier ni soin inutiles : PA et temps gagnés) ; l'estimation est prudente (dégâts moyens × 0,85, résistances et malus de la cible compris). Cible : l'ennemi qui a le moins de PV. **Retrait de PA** (Précipitation, Odorat…) : chaque PA retiré Affaiblit l'ennemi (sa prochaine attaque −15 %, 60 % au plus) ; le pilote vise l'ennemi qui frappera le plus fort sans être déjà affaibli (sauf s'il peut achever le plus faible), et le plan de tour de l'Ascension compare cette cible à la plus menaçante pour garder la meilleure suite, deux retraits sur le même ennemi dans un tour comptés ensemble. Contre la **Fureur** (Hell Mina…), un retrait de PA sur le boss qui la porte (Précipitation : −3 PA, sa prochaine attaque −45 %) ramène son attaque déchaînée de ×2,5 à ×1,375 : le plan de tour le compte et peut alors jouer plus de cartes que la limite. Le plan de tour compte aussi le **bonus « une ligne » perdu** : un sort à plusieurs lignes (ou l'arme) le remet à zéro et sa montée (+20 % par tour) est perdue pour les tours suivants ; l'arme n'est plus jouée à chaque tour si elle coûte plus qu'elle ne rapporte. La règle « tous les N tours » repart de zéro à chaque nouveau combat (un essai précédent du même étage bloquait Bouclier Féca). **Reflet** (Obsidiantre, Hell Mina…) : chaque tour, le boss annonce un élément qui ne le blesse pas et dont une part des dégâts te revient (50 %, 100 % pour les mécaniques annoncées) ; le pilote (et le plan de tour de l'Ascension) ne le frappe pas avec un sort de cet élément ce tour-là. **Mécaniques annoncées** (Ascension dès l'étage 50, boss « Transmutés » dès le 101, Dimension écarlate…) : le jeu les annonce au tour 1 et l'état du combat les donne ; le pilote (et le plan de tour de l'Ascension) gère :
- les **Gardiens** : le boss est invulnérable tant que ses gardiens sont debout : il n'est pas visé (sorts de zone compris) et pas de coup final sur lui ;
- l'**Élément mouvant** : l'élément annoncé en début de tour soigne le boss : pas de sort de cet élément sur lui ;
- l'**Épuisement final** : à partir du tour qui suit l'annonce, le pilote passe son tour sans attaquer (boucliers, soins et buffs restent permis) ; pendant le tour de l'annonce, il peut encore l'achever ; tant que d'autres boss sont debout, il évite de faire passer ce boss sous sa limite (avec une marge) pour ne pas perdre deux tours sous leurs coups, et ne le descend qu'une fois seul (ou en l'achevant d'un coup) ;
- l'**Inversion** : ni soin ni bouclier pendant ses tours ;
- la **Flétrissure** : soins et boucliers comptés à leur valeur réduite ;
- le **Sceau** « premier sort du tour +2 PA » : le surcoût est compté sur le premier sort (pas l'arme) ;
- le **Seuil de douleur** : aucun coup ne retire plus de x % des PV max du boss (le Reflet, lui, renvoie le coup entier) ;
- le **Lien d'âme** : les autres boss subissent moins de dégâts tant que son porteur est debout, et reprennent des PV s'il tombe avant eux : il est abattu en dernier ;
- l'**Écho** : le boss renvoie le dernier sort du tour (selon ses PA) : le pilote finit plutôt par l'arme, un soin ou un bouclier, ou par un petit sort ;
- le **Glas** : une fois sonné, le boss est visé en priorité (sinon il frappe très fort), jusqu'au dernier tour pour le briser, où le pilote accepte de payer un peu (Onde de choc, carte en plus) si la suite le brise : les dégâts absorbés par son bouclier comptent ;
- la **Hâte** : le tour où le boss agit deux fois, le pilote garde deux fois plus de PV de marge.

**Hors Ascension** (Dimension Écarlate…), un combat contre des boss Transmutés est joué avec le même plan de tour que l'Ascension (ordre et cibles des cartes, coups renvoyés comptés, Dofus Pourpre compris) au lieu des seuls poids : un sort à plusieurs éléments dont l'un est renvoyé par le Reflet n'est plus lancé quand le renvoi met en danger. Le plan de tour compte au pire ce qui revient : un sort de zone dont la cible meurt en cours de lancer frappe le boss suivant à 100 % (et non 60 %), les lignes d'un sort à une cible qui l'a achevée partent sur l'ennemi suivant, un boss dont le sort abat tous les gardiens est touché par les lignes suivantes, et la Vision spectrale peut doubler un renvoi ou un vol de vie maudit ; un sort qui pourrait ainsi te faire passer sous l'attaque annoncée des boss n'est pas joué.

La Carapace (bouclier du boss, compté comme tout bouclier), la Malédiction (carte la plus jouée scellée par le jeu), la Rancune, l'Échange de PV, la Métamorphose et l'Accoutumance (résistances lues dans le combat) sont reconnues sans parade particulière. En Ascension, les mécaniques cachées de chaque boss (Fureur, Miroir, Onde de choc…) sont maintenant lues dans l'état du combat, avec leurs valeurs exactes (tours du Miroir, nombre de cartes de la Fureur) : plus besoin de les deviner par l'étage et le bestiaire. Chaque essai enregistre aussi ces mécaniques (cachées et annoncées) pour l'étage, et l'essai suivant (le tien ou celui d'un ami de la synchro) s'en sert avant même le combat : le **deck conseillé** (🧠 sur la page Ascension, 7 cartes : le minimum du jeu) fait jouer chaque deck candidat contre le Reflet et l'Élément mouvant (un élément différent à chaque tour simulé), les gardiens, l'Inversion, la Flétrissure, le Sceau et le vol de PA, écarte les soins et les vols de vie quand le premier boss (celui qui impose ses mécaniques) a une Malédiction des soins, et explique ses choix (sort multi-éléments renvoyé par le Reflet, carte peu chère contre le vol de PA, zone contre les gardiens, bouclier réduit par la Flétrissure…) ; la **marge de survie** de l'optimiseur (objectif Ascension) compte la Rancune, la Carapace, les gardiens et la Métamorphose (PV à percer en plus), le Reflet, l'Élément mouvant et les PA perdus (moins de dégâts par tour), l'Épuisement final (tours à passer sous les coups) la Flétrissure (boucliers réduits), le Seuil de douleur des Transmutés (chaque coup plafonné à 6 % de ses PV : c'est le nombre de lignes de dégâts qui compte, plus la puissance), la Fureur (seules les N meilleures cartes du tour comptent) et le Lien d'âme (PV rendus aux autres boss à sa chute) : à l'étage 126, elle tombe de 2,25 à 0,61, plus proche des défaites réelles. Par défaut : gain de PA 100, buffs 90 (relancés à la fin de leur durée), soins 80, dégâts selon leurs dégâts de base par PA, arme 30. En cas de souci (état illisible, réponse inattendue), le combat repasse sur l'Auto du jeu.

**🤖 Pilote full auto** (case sur le panneau 🧠 de la page Ascension) : avant chaque étage, et de nouveau après chaque défaite, le pilote lance l'optimiseur en objectif Ascension (survie) contre les boss de l'étage avec **tes seuls objets à leur vrai tier** (inventaire et équipement porté : rien n'est simulé en Rayonnant, ni HDV, ni banque, ni drops), équipe le build trouvé, répartit tes points, puis recalcule et active le deck conseillé. Rien à changer : l'étage est relancé tel quel. L'auto-équipement passe sur Off. Le deck est conseillé avec les stats du dernier combat : après un changement d'équipement, il se recale à l'essai suivant. Chaque défaite relance le calcul. Un deck qui a déjà perdu 3 fois au même étage n'est plus reproposé tel quel : le pilote essaie la meilleure variante (une carte changée) pas encore épuisée, et ainsi de suite.

**Combat lancé à la main** (Kralamoure, boss…) : le bouton **🎯 Jouer ce combat par poids** (en bas à droite de `/combat`) joue ce combat-là avec les mêmes poids, sans le pilote et sans relance à la fin ; recliquer l'arrête.

**🐙 Contre le Kralamoure** (reconnu à son nom, combat de 10 tours sans danger), le moteur par poids change de règles :
- jamais de soin, bouclier, régénération ni buff défensif, même sous le seuil de PV ;
- les invocations, le Portail et la pioche restent joués ;
- un buff ou un debuff offensif (stats de dégâts, PA ou PO sur toi, % de résistance retirés au Kralamoure comme la carte Proie) n'est relancé que quand son effet est terminé : le jeu indique quelle carte a posé chaque buff et combien de tours il lui reste. Il passe avant les dégâts du tour, et n'est plus lancé au dernier tour, sauf s'il donne des PA ;
- sorts à une ligne : si jouer seulement des sorts à une ligne de dégâts rapporte plus sur les tours restants (même calcul que l'optimiseur), les sorts et l'arme à plusieurs lignes de dégâts sont écartés. Au dernier tour, ils sont joués en dernier.

Le journal du moteur l'indique : « [Kralamoure, 7 tours restants, sorts à une ligne] ».

**🎲 Victoire estimée** (popup → État, et menu 🤖 sous l'état du pilote), pendant un combat : part de victoires sur 300 simulations de la suite du combat. Elles partent de tes PV et boucliers, et de tes dégâts et soins par tour (appris sur tes combats, séparément pour l'Auto du jeu et l'Auto par poids ; ce combat-ci compte pour 70 % dès 2 tours joués). Côté ennemis, elles partent de leurs PV, de l'action qu'ils annoncent et de leur cycle d'actions (attaque, coup lourd, drain…, avec les dégâts réels appris pour chaque type). « Apprentissage… » tant que moins de 3 combats ont été vus. En Auto du jeu, le serveur joue tout le combat d'un coup : l'issue s'affiche dès qu'elle est connue, à côté de l'estimation de départ. **Pronostics justes** : part des estimations de départ qui ont vu juste (≥ 50 % → victoire), après 5 combats.

**⏱ Chronomètre des combats** (menu 🤖, sous le bouton Démarrer) : durée moyenne d'un combat (lancement → écran de fin) et de la boucle complète (d'un lancement au suivant, avec le combat par heure), par activité et par mode de combat, pour comparer l'Auto du jeu et l'Auto par poids sur la durée. Les pauses de plus de 5 min ne comptent pas ; ↺ remet à zéro.

## Auto-équipement

Dans le menu 🤖 en jeu, section **🛡️ Auto-équipement** : choisis jusqu'à 5 caractéristiques par ordre de priorité (la 1re compte pleinement, la 2e pour 35 %, la 3e pour 15 %, les 4e et 5e, facultatives, pour 8 % et 4 %) ; un emplacement vide est toujours rempli, même par un objet qui n'a aucune de ces stats et les emplacements à optimiser (clic sur un emplacement pour l'activer ou le désactiver). **🔍 Aperçu** montre les objets qui seraient équipés et l'écart de stats, **✅ Équiper** les équipe. Les bonus de panoplie ne sont pas pris en compte.

Le sélecteur **Off / Semi / Auto** vérifie l'inventaire toutes les 3 minutes par défaut (réglable dans la popup → Réglages, « Auto-équipement : vérif. » ; jamais pendant un combat) :
- **Auto** équipe directement les meilleurs objets ;
- **Semi** ouvre une fenêtre qui propose chaque changement avec l'écart de stats (gagnées en vert, perdues en rouge) : **✔ Équiper** ou **✖ Non** (l'objet n'est plus jamais proposé ; **↺ Oublier** efface ces refus). Fermer la fenêtre avec ✕ la repropose 30 minutes plus tard.

## Tout retirer

Menu 🤖 → Fusion → **🔓 Tout déverrouiller** : ouvre le cadenas de tous tes objets verrouillés en jeu (2e clic pour confirmer), une pile après l'autre.

Sur `/personnage` (onglet Équipement et objets), le bouton **🧺 Tout retirer** (à gauche de « Vendre ou briser plusieurs objets ») retire tous les objets portés (2e clic pour confirmer), puis recharge la page.

## Échange entre deux comptes

Connecte un compte dans une fenêtre normale et l'autre dans une fenêtre de navigation privée. Sur `/personnage` (onglet Équipement et objets) ou dans l'onglet *Vendre* de l'HDV :

- **🔁 Échanger** sur un objet : il est mis en vente à un petit prix aléatoire (11 à 49 kamas, pour ne pas se faire racheter par des tiers) et l'autre compte l'achète aussitôt.
- **➕ File** ou **📋 Sélection** (panneau en haut à droite) : prépare plusieurs objets, puis **Tout échanger**. Un récap s'affiche à la fin (envoyés, perdus, non envoyés, sautés) et **🕘** ouvre l'historique de tous les échanges.

**Tout échanger** envoie deux objets à la fois : le suivant est mis en vente pendant que l'autre compte achète le précédent (jamais deux exemplaires du même objet en même temps). L'échange ne fonctionne qu'entre les onglets de ton propre navigateur. Si l'achat échoue, l'annonce est retirée automatiquement.

## Tierlist des sorts

Menu 🤖 → **📚 Tierlist des sorts** : relit ta collection (/deck) à chaque ouverture et classe tous tes sorts à dégâts. Toutes les lignes de dégâts d'un sort sont additionnées, même sur des éléments différents ; les lignes à x % de chance comptent en moyenne (🎲). Filtres cible unique / zone, élément (ou multi-éléments), favoris ; tris par dégâts totaux, dégâts par PA, coût en PA ou nom (re-clic = sens inverse). Le cadenas 🔓/🔒 met le sort en favori sur le site. Par défaut : dégâts de base des cartes. L'interrupteur **Avec mes stats** recalcule avec tes caractéristiques (lues sur ton dernier combat), sur une cible sans résistances. **🧪 Tester le calcul** compare l'estimation aux vrais coups de ton dernier combat (« Copier le récap » pour l'envoyer). Les sorts dont les dégâts dépendent de la vie ne sont pas classés.

## Optimiseur de build

Menu 🤖 → **🧬 Optimiser mon build** : cherche l'équipement qui maximise tes dégâts sur un tour, c'est-à-dire la meilleure combinaison de N sorts de dégâts (réglable) qui tient dans tes PA, sur **tes cibles habituelles** (résistances des monstres que tu combats, apprises à chaque combat ; sans résistances tant qu'il y a moins de 5 monstres appris). Prend en compte la fusion, le prestige (+25 % de stats d'équipement par niveau) le Bouclier de forge (son bonus s'ajoute à celui du prestige, lu sur /forgemagie) et le Compagnon (+0,2 % par niveau, lu sur /compagnon), les PA gagnés par l'équipement les PA et PO du Prestige (P1/P4/P7 +1 PA, P2 +2 PO, P5 +3 PO), les parchemins d'arène, et les **bonus de panoplie** : ceux des panoplies que tu as déjà portées sont lus sur ta fiche (le jeu ne suit pas toujours dofusdb) et retenus ; les autres viennent de dofusdb (palier N − 1 pour N objets). Options : **Redistribuer mes points** (coché par défaut : tous tes points de caractéristiques sont considérés comme redistribuables, l'optimiseur choisit équipement et répartition ensemble, en tenant compte des paliers de coût ; bouton **📊 Appliquer cette répartition** : réinitialise si une stat doit baisser, puis répartit les points, 2e clic pour confirmer), **PV minimum** (vide = sans contrainte, atteint d'abord via la Vitalité), **PA minimum** (vide = sans contrainte), **Inclure la banque** (objets de ton autre compte, onglet ouvert dans l'autre fenêtre, sauf ceux encore liés < 24 h ; bouton 📦 pour les mettre dans sa file d'échange), **Tolérance mes objets** (en %, vide = 0 : le meilleur build d'où que viennent les objets ; sinon un objet à acheter ou looter est remplacé par un objet que tu as tant que le build reste à moins de ce pourcentage du meilleur), **sorts du deck actif uniquement**, **fouiller l'HDV** (objets en vente proposés avec leur prix). Avec l'HDV : champ **Budget** (vide = sans limite) pour que tous les achats du build tiennent dedans, bouton **🛒 Acheter** (2e clic pour confirmer) sur chaque objet à acheter, et **🚫** pour mettre un objet en liste noire (liste consultable dans la fenêtre, ✕ pour en retirer). **✅ Équiper ce build** équipe les objets que tu possèdes (y compris ceux que tu viens d'acheter) ; l'inventaire est relu juste avant : si tu n'as plus l'objet au tier retenu, il équipe ton exemplaire au plus haut tier. Équiper un build optimisé passe l'auto-équipement (Semi/Auto, fait pour l'XP) sur Off. **🃏 Deck conseillé** : sorts offensifs, plus le meilleur bouclier 🛡️ et le meilleur soin 💚 par PA pour le build proposé (sauf si ton deck 3 en contient déjà) ; toujours **7 cartes au moins** (minimum du jeu), complété au besoin par les sorts suivants. **📋 Copier le code** copie le code du deck (DM-S-…) à coller dans « Importer un code » sur /deck ; **Écrire dans le deck 3** l'enregistre directement (2e clic pour confirmer), ses autres cartes sans dégâts (📌) conservées. Nombre de sorts offensifs réglable (le deck a au plus la taille donnée par /deck) ou **auto** (par défaut) : la main se pioche au hasard dans le deck, et le bonus de deck donne +5 % aux sorts par carte au-delà de 7, jusqu'à +25 % à 12 cartes. En auto, le deck (sorts conseillés + tes autres cartes) est complété jusqu'à 12 cartes avec les sorts suivants tant que chacun vaut au moins la moitié environ de la moyenne des sorts retenus (plus faible, il dilue la pioche plus que le bonus ne rapporte) ; au-delà de 12, plus de bonus : un sort n'est ajouté que s'il bat la moyenne. La fenêtre affiche la taille du deck et son bonus. À la réouverture, la fenêtre réaffiche ta dernière recherche (photo de ce moment-là ; « Lancer » la refait). « Contrôle du modèle » compare les stats calculées pour ton équipement actuel à ta fiche personnage. Le calcul d'un tour (meilleure combinaison de sorts) est environ 5 fois plus rapide depuis la 2.27.1, et l'objectif Ascension ne refait plus toute la répartition des points pour chaque part de Vitalité essayée : la recherche est nettement plus courte, pour le même résultat.

**🗡️ Pénétration et réduction de dégâts.** Depuis la mise à jour du jeu, les lignes « % Dommages distance » et « % Dommages mêlée » des objets et panoplies donnent de la **Pénétration** : chaque point ignore 0,8 % de résistance élémentaire en % de la cible (pas les résistances fixes), 50 points au plus (40 % ignorés), sans jamais descendre sous 0 (une faiblesse reste entière). Les malus de ces lignes ne comptent pas, et le prestige, la forge et le bonus Discord les multiplient par 3 au plus. Les lignes « % Résistance distance » et « % Résistance mêlée » donnent de la **Réduction de dégâts** : −1 % des dégâts subis par point, avant les résistances, 50 % au plus. L'extension en tient compte partout où elle calcule des dégâts : Auto par poids (coup final compris), plan du tour en Ascension, victoire estimée, test du calcul et auto-diagnostic, marge de survie en Ascension, optimiseur.

Pour savoir ce que la pénétration rapporte vraiment, l'extension retient les résistances de chaque monstre au lancement de chaque combat (1 500 monstres au plus, avec le nombre de rencontres). L'optimiseur s'en sert comme cible par défaut : les monstres de ton niveau (−25 / +10), ou tous s'il y en a moins de 15. Le résultat affiche une ligne **🗡️ Pénétration** avec :
- les résistances moyennes de tes cibles par élément ;
- tes points de pénétration et ce qu'ils rapportent, actuels → build proposé ;
- le gain au maximum (50 points) ;
- le nombre de points au-delà duquel elle ne sert plus, quand toutes les résistances positives de la cible sont déjà annulées.

La pénétration est aussi comparée à ta fiche dans le « Contrôle du modèle ».

**💎 Dofus.** Un Dofus en Rayonnant +5 a toutes ses stats ×2, PA compris. C'est vérifié sur l'aperçu des 27 Dofus du coffre de Dofus au choix, à l'unité près. Depuis le 16/10, la fusion monte les Dofus et les trophées jusqu'au Rayonnant +5, comme les autres objets : l'optimiseur les simule au tier choisi. Les objets légendaires (les « Mehdita… », qui ne se fusionnent pas) restent toujours à leur vrai tier. Leurs PA s'ajoutent au-delà du plafond de PA (16 PA au plafond de 15 avec l'Arme Mehditaclaque), et l'optimiseur les compte ainsi. Depuis le 17/10, chaque objet de la pano Mehdi porté (les 11 légendaires) donne +20 % de ses propres stats (hors PA, PM et PO) et +2 % de dégâts de sorts : l'optimiseur les ajoute, comme les runes. La case **Dofus en Rayonnant +5** compte tous les Dofus en +5, comme ceux du coffre au choix ou l'objet éternel du Prestige. Pratique pour choisir quel Dofus prendre.

**💠 Runes.** L'optimiseur lit les runes de tes objets (portés et inventaire) et les ajoute à leurs stats, comme le jeu : bonus fixes (Vitalité, Dommages, PM…), Rune d'Éveil (+15 % de toutes les stats de l'objet) et d'Éclat (+5 %), Rune Élémentaire (dommages élémentaires de l'objet doublés), une seule Rune d'Action comptée. Au tier simulé, les runes suivent l'objet. Elles comptent avant le Prestige, la forge et le compagnon.

**💡 Objet éternel du Prestige.** Sur `/personnage`, sous le bouton « Faire Prestige » et sous « Objet gardé », une bulle propose 5 objets à rendre éternels (Rayonnant +5, quel que soit l'exemplaire choisi). Le classement multiplie les stats gagnées par le farm que l'éternel t'évite. Un objet qu'aucun monstre du bestiaire ne lâche (coffre, boutique, familier…) passe en tête. Viennent ensuite les objets des Boss du Chemin, puis les drops, selon le nombre de monstres à vaincre pour réunir les 81 exemplaires manquants. La raison est affichée sur chaque ligne.

Les nouveaux Dofus d'octobre 2026 (Cawotte, Dokille, Veilleurs, Dotruche, Domakuro, Dorigami, Dofoozbz, Forgelave, Cacao, Dom de Pin) sont reconnus mais pas calculés : butin, XP, pioche, PA ou soins. Le Dolmanax (+10 % de dégâts dans son élément, donné par le jeu en combat) est compté dans le test du calcul.

**⚔️ Passifs de classe.** Le calcul des dégâts (test du calcul, plan du tour, Auto par poids, Ascension, optimiseur) suit les passifs de la V3 du jeu (13/10) : Armure Féca −4 % / +4 % par charge (20 % au plus ; les charges durent tout le combat, tout sort qui soigne ou protège le Féca en donne une, vols de vie comme Tromperie compris, et le bonus compte aussi pour l'arme), Avarice +5,5 % par Pièce (10 au plus), Assassinat +33 % sous 50 % de PV et +66 % sous 25 %, Distorsion +6,6 % par charge (10 au plus), coups de chance de l'Ecaflip à 32 %, Mots +9,9 %, Souffrance +7 % par tranche de 10 % de PV manquants, Ivresse +5 % (6 niveaux), Artificier +11 % par bombe (+33 % au plus), Évolution +7,7 % (6 évolutions), Portails une attaque sur 2 à +50 %, Runes +11 %, Lance projetée +45 %… Les combats enregistrés avant restent calculés avec les passifs de leur époque (avant le 10/10, puis du 10/10 au 13/10).

**Prestige** : les bonus de dégâts et de soins du passif montent de +5 % par Prestige depuis la V3 (+10 % avant ; ×1,5 au Prestige 10). Les réductions de dégâts subis et les chances ne changent pas. Le journal du combat affiche toujours la valeur sans Prestige, mais les dégâts suivent bien la valeur boostée (vérifié sur 233 coups). Les sorts de **ta** classe sont aussi renforcés par Prestige : +10 % pour les sorts de dégâts (boucliers et soins compris), +2 % pour les sorts de boost (Bouclier Féca 33 → 66 et Masque du Psychopathe 41 → 49 au Prestige 10). En combat, le jeu donne déjà les valeurs boostées ; l'optimiseur et la tierlist des sorts, qui lisent les valeurs de base de la page Deck, appliquent maintenant ce bonus eux-mêmes (avant la 2.28.0, les sorts de classe y étaient sous-estimés).

**🎯 Bonus des sorts (patch d'octobre 2026, hors Abysses).** Le calcul des dégâts (test du calcul, plan du tour du moteur de combat) compte :
- les **sorts à une seule ligne** : +50 % de dégâts, puis +20 % par tour, jusqu'à +150 %. Un sort ou un corps à corps à plusieurs lignes remet le bonus à zéro, il repart au tour suivant. Depuis la mise à jour du 12/10, seules les **lignes de dégâts** comptent (dégâts, vol de vie, poison, bombe, piège) : un sort avec une ligne de dégâts et des lignes de boost, debuff, soin ou retrait de PA (Ponteira, Nimbus, Lance-flamme, Dents du Piranya) garde le bonus ; La Bêche à Mel (Feu + Eau) le remet à zéro ;
- les **grands decks** : +5 % de dégâts des sorts par carte au-delà de 7, jusqu'à +25 % (aussi dans la marge de survie en Ascension). Les deux bonus **s'additionnent** : un sort à une ligne au tour 1 avec un deck de 12 cartes ou plus fait +75 % (pas ×1,25 × 1,5 = +87,5 %), +95 % au tour 2, etc. Vérifié le 13/10 sur 474 coups en Ascension : 97 % dans la fourchette estimée, contre 33 % en multipliant les bonus. L'optimiseur en tient compte quand il compare les façons de jouer ;
- la nouvelle **Proie** de l'Ouginak : +12 % par sort qui a déjà frappé la proie, jusqu'à +60 %, corps à corps compris, seulement sur la proie.

Sur 4 combats capturés après le patch, le test du calcul passe de 41 à 63 coups sur 81 dans la fourchette estimée (15 → 25 sur 25 pour le meilleur). Les écarts restants viennent surtout des résistances de certains boss, qui changent en cours de combat. Le moteur de combat ne cherche pas encore à garder le bonus des sorts à une ligne : il le compte, mais ne renonce pas à un sort à plusieurs lignes pour le préserver.

**🎯 Dans l'optimiseur** (case **Bonus des sorts à une ligne**, cochée par défaut) : pour chaque build, deux façons de jouer sont comparées et la meilleure est gardée :
- **tour à une ligne** : seulement des sorts à une ligne, avec le bonus moyen sur la durée de tes combats (apprise par la victoire estimée, 4 tours sans mesure) : +70 % sur 3 tours, +80 % sur 4, +100 % sur 6. Avec l'objectif **🐙 Dégâts sur Kralamoure**, la durée est fixée aux 10 tours du combat : bonus moyen de +120 %, et le Dofus Pourpre est réparti sur 10 tours (voir plus bas) ;
- **tour mixte** : un sort à plusieurs lignes par tour remet le bonus à zéro, il repart à +50 % le tour suivant. Les sorts à une ligne, lancés avant, gardent +50 % ; ceux à plusieurs lignes n'ont rien.

En pratique, un sort à plusieurs lignes ne garde sa place que s'il fait à peu près deux fois les dégâts par PA de tes sorts à une ligne. Les stats suivent : en tour à une ligne, chaque sort ne frappe que dans un élément, donc les points d'élément et la Puissance se concentrent sur les éléments des sorts gardés, et les Dommages fixes (comptés une fois par ligne) valent moins. Le résultat affiche une ligne **🎯 Sorts à une ligne** : façon de jouer retenue, dégâts par tour des deux façons, et le bonus de chaque sort du tour.

**L'arme** : celle de ton dernier combat est vérifiée. Si elle a plusieurs lignes (comme La Bêche à Mel), la jouer chaque tour bloque le bonus à +50 % : l'optimiseur compte alors +50 % et affiche ce que donnerait une arme à une ligne, ou ne pas la jouer. Les dégâts de l'arme elle-même ne sont pas comptés par l'optimiseur.

**🐙 Kralamoure (combat de 10 tours).** Avec l'objectif **Dégâts sur Kralamoure**, l'optimiseur vise le total sur les 10 tours, pas un seul tour :
- **buffs et debuffs entretenus** : chaque carte qui booste tes dégâts (buff de stats, de PA ou de PO sur toi) ou retire des % de résistance à la cible (carte Proie : −20 % tous éléments, 3 tours) est comptée comme relancée à chaque expiration. Son coût en PA est réparti sur sa durée (1 PA pour 3 tours = 1/3 de PA par tour), et elle n'est gardée que si elle rapporte. Un sort de dégâts qui porte un buff (Dents du Piranya : +20 Dommages) l'entretient s'il est joué à chaque tour. Les stats et les objets sont choisis avec ces effets actifs. Les cartes gardées sont choisies une fois, sur ton équipement actuel, puis fixées pendant la recherche (la recherche reste aussi rapide qu'en mode normal) ;
- **plan tour par tour** (ligne 🐙, détail dépliable) : le build actuel et le build proposé sont joués sur 10 tours avec le passif de ta classe (lu sur ton dernier combat : Proie qui monte de +12 % par coup jusqu'à +60 %, Enchaînement…), le bonus des sorts à une ligne exact (+50 % puis +20 % par tour, remis à zéro par un sort à plusieurs lignes de dégâts), le bonus de grand deck, les buffs avec leur durée et le Dofus Pourpre au 1er sort. Chaque tour, l'enchaînement est choisi avec ou sans une carte de buff de plus, sa valeur comptée sur ses tours restants. Les deux façons de jouer (sorts à une ligne de dégâts seulement, ou tout) sont essayées et la meilleure est affichée.

Hypothèses du plan : tes cartes sont toujours en main (le tirage aléatoire de 5 cartes n'est pas simulé), PA de base chaque tour, dégâts de l'arme non comptés. Le Dofus Turquoise est compté dans les dégâts par tour, pas dans le plan. Le passif de classe ne change pas le choix des objets (il multiplie tous les builds pareil) : il sert au total et à l'ordre des sorts.
